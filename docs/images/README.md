# Screenshots

The README shows five screenshots of the running app. Until you replace them, each one is a grey placeholder with the same file name, so nothing breaks. Replace a file by saving your screenshot over it with the **same name**.

| File | What to capture |
|---|---|
| `screenshot-gallery.png` | The Gallery page with a few days of photos visible, upload box at the top |
| `screenshot-people.png` | The People page with several people (give two or three of them names first) |
| `screenshot-person.png` | One person's page: their name (editable) and their photos |
| `screenshot-viewer.png` | A photo open full screen so the face boxes are visible |
| `screenshot-upload.png` | The upload box with files selected, or the progress bar during an upload |

Tips

* Browser window about 1440 x 900, then crop to roughly 16:10 (the placeholders are 1600 x 1000). PNG or JPEG under about 500 KB each keeps the README fast.
* Use photos you own, or have permission to show, and avoid showing other people's faces without their consent. Public-domain or Creative Commons portraits work if you credit them.
* Light mode for all five is fine. A dark-mode shot can be added to the README later if you like.
* Once the real screenshots are in, you can delete this file.

The `fig-*.png` files next to these are the evaluation graphs. They are drawn by `docs/make_figures.py` from the committed results; do not replace them by hand.
